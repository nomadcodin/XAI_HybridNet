# Explainability Visualizations

This folder contains multimodal explainability outputs generated by the proposed XAI-HybridNet framework and baseline architectures.

## Included Figures

### gradcam_visualization.png
Grad-CAM heatmap visualization highlighting spatially important pulmonary regions.

### guided_gradcam_visualization.png
Guided Grad-CAM visualization combining gradient localization with fine-grained feature attribution.

### vit_attention_map.png
Vision Transformer attention visualization illustrating global contextual focus regions.

### hybrid_attention_map.png
Hybrid multimodal attention map combining CNN-based localization and Transformer contextual reasoning.

### hybrid_multimodal_explanation.png
Integrated multimodal explainability output combining multiple explanation mechanisms.

### lime_superpixel_explanation.png
LIME-based superpixel feature importance visualization.

### shap_attribution_analysis.png
SHAP attribution visualization illustrating positive and negative regional contributions.

### shap_region_attribution_comparison.png
Comparative SHAP region attribution analysis across ResNet-50, ViT-B/16, and HybridNet architectures.
