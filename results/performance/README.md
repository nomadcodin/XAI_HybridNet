# Performance Evaluation Results

This folder contains the quantitative performance evaluation and model benchmarking results for the proposed XAI-HybridNet framework.

## Included Figures

### metric_comparison.png
Comparative evaluation of ResNet-50, ViT-B/16, and HybridNet across Accuracy, Precision, Recall, and F1-score metrics.

### mcnemar_analysis.png
McNemar statistical significance analysis comparing HybridNet against baseline architectures.

### resnet_training_accuracy.png
Training and validation accuracy curves observed during ResNet-50 optimization.

### resnet_training_loss.png
Training and validation loss curves illustrating convergence behavior and overfitting characteristics.

### reliability_calibration.png
Reliability calibration diagram and Expected Calibration Error (ECE) analysis for prediction confidence evaluation.

### faithfulness_evaluation.png
Faithfulness deletion and insertion evaluation curves assessing explanation reliability and feature importance consistency.
